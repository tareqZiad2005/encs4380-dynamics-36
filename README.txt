## Project Overview

This project is an interactive educational toolkit developed for the ENCS4380 course. Its goal is to help students understand and explore the dynamic characteristics of measurement systems through interactive simulations, visualizations, and practical examples.

The toolkit consists of four modules covering first-order and second-order system behavior, frequency response, and parameter estimation.

## Project Modules

The toolkit includes four interactive modules:

1. **First-Order Time Response** – Explores step and ramp responses, time constants, and transient behavior.
2. **First-Order Frequency Response** – Demonstrates amplitude ratio, phase lag, Bode plots, and dynamic error.
3. **Second-Order System Response** – Visualizes damping behavior, response characteristics, poles, eigenvalues, and state-space representations.
4. **Guess the Sensor** – Challenges users to estimate unknown sensor parameters based on simulated responses.
