Module 1 — First-order time response

Explore a first-order sensor

A first-order sensor does not respond instantly. Its time constant, τ, determines how quickly its output approaches the input's steady-state value.

τ dy/dt + y = Kx

For a step input of amplitude A, the response is y(t) = KA(1 − e−t/τ).

Error-fraction plot (logarithmic vertical axis)

For a step response, the error fraction is em(t) = e−t/τ. Taking the natural logarithm gives a straight line: ln(em) = −t/τ, whose slope is −1/τ.
