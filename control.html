P1 · PID playground

The controller looks at the error e = r − y and decides how hard to push the plant. Each term answers a different question: P reacts to the error now, I to the error that has built up, and D to how fast the error is changing.

u(t) = Kp·e(t) + Ki·∫e dt + Kd·de/dt

P2 · A slow sensor in the loop

The controller never sees the true output. It sees what the sensor reports, and a first-order sensor reports the past, smoothed (Homework 1). The controller keeps pushing because the reading still looks low, and by the time the reading catches up the true output has already gone past the setpoint.

P3 · Digital PID

An Arduino cannot integrate or differentiate. Every Ts seconds it reads the sensor once, computes one value of u, and holds it until the next sample. The sum replaces the integral and the difference replaces the derivative:

u[k] = Kp·e[k] + Ki·Ts·Σ e[j] + Kd·(e[k] − e[k−1]) / Ts

Here the controller runs this formula exactly, and the plant between samples is solved with RK4. The grey dashed curve is the same gains run as an ideal continuous controller.

When on, the sum stops growing while u is stuck at its limit.
